Useful Commands — DNS Resolution Test Suite (Live Dig)

Uji kemampuan resolusi DNS secara langsung pada port 53 (dnsdist IPv4/IPv6) dan port 5300 (unbound backend recursive)

Port 53 • Frontend IPv4

Test DNS IPv4

dig @127.0.0.1 <domain>

Menguji routing masuk dnsdist IPv4 loopback

Port 53 • Frontend IPv6

Test DNS IPv6

dig @::1 <domain>

Menguji antarmuka IPv6 dnsdist loopback

Port 5300 • Backend Recurser

Test Recursive Resolver

dig @127.0.0.1 -p 5300 <domain>

Menguji langsung resolver recursive Unbound

All-in-One Benchmark

Uji Semua Resolusi

dig IPv4 + IPv6 + Recurser

Menjalankan ketiga pengujian sekaligus dan membandingkan hasilnya

Useful Commands — Check Configuration

Validasi sintaks sebelum restart service

Check Unbound Config unbound-checkconf Validasi file /etc/unbound/unbound.conf
Check DNSDist Config dnsdist --check-config Validasi skrip Lua /etc/dnsdist/dnsdist.conf
Periksa Keduanya Sekaligus Jalankan validasi Unbound dan DNSDist dalam 1 klik

Useful Commands — Service Control

Cek status real-time & restart daemon sistem

unbound (Recursive) systemctl [status|restart] unbound
dnsdist (Frontend LB) systemctl [status|restart] dnsdist
Restart Kedua Service systemctl restart unbound && dnsdist

Useful Commands — Telemetry & System Metadata

Kirim heartbeat manual dan periksa berkas environment registrasi SmartDNS

Manual Heartbeat

/usr/local/bin/smartdns-heartbeat

Kirim deteksi hardware dan telemetri langsung ke server pusat monitoring SmartDNS (tanpa jeda sleep).

View Installation Metadata

cat /var/lib/smartdns/install.json

Tampilkan data JSON UUID instalasi, rilis versi, tanggal pemasangan, dan izin telemetri node ini.

View Installation Path

cat /var/lib/smartdns/install.env

Tampilkan variabel direktori dasar instalasi SmartDNS (SMARTDNS_HOME=/root/SmartDNS).
